NP Membership Benefits

NP Membership is available to nonprofit organizations with no membership fee.

  • Chamber directory listing
  • Networking opportunities
  • Community events
  • Access to chamber information

Bronze Membership Benefits

Bronze Membership provides affordable benefits for developing businesses.

  • Directory listing
  • Networking opportunities
  • Selected training events
  • Business development resources

Silver Membership Benefits

Silver Membership provides additional promotional and networking opportunities.

  • Enhanced directory listing
  • Training opportunities
  • Event discounts
  • Social media promotion
  • Networking events

Gold Membership Benefits

Gold Membership provides the highest level of chamber visibility and benefits.

  • Premium directory listing
  • Home page spotlight opportunities
  • Advertising opportunities
  • Special event sponsorship opportunities
  • Training and networking benefits
  • Event discounts
